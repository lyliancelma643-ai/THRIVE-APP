# GlassButton

Bouton de barre de navigation en Liquid Glass, 44 pt de haut, en capsule.

- Variantes : icône seule (44 × 44), texte, paire d'icônes groupées, teinté (`tint` / `tint-ink`) pour la validation.
- Bord `glass-edge` + reflet `shadow-glass`, jamais d'ombre portée (iOS 27).
- Une seule action teintée par barre (OK, Terminé). « Annuler » reste neutre.
- Le consommateur fournit : l'icône SF Symbol ou le libellé, le libellé d'accessibilité pour une icône seule.
