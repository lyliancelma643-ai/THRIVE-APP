# Sheet

Feuille modale iOS 27 : en grand détent (coins `radius-sheet`, collée aux bords) ou en détent moyen flottante en verre (`radius-sheet-float`, 8 pt des bords).

- Poignée 36 × 5 en `label-3`, barre de titre 17 pt semibold, bouton Fermer en GlassButton à droite.
- La version flottante sert aux explications courtes (« Comprendre l'outil », « Ton espace se prépare ») ; le grand détent aux détails chiffrés (Compétences de vie).
- Fond assombri à 18–28 % derrière.
- Le consommateur fournit : titre, contenu, détent, action principale éventuelle.
