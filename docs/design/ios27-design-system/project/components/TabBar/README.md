# TabBar

Barre d'onglets flottante en Liquid Glass : trois onglets dans une capsule et un onglet Prominent détaché, rond et teinté.

- Hauteur `tabbar-h` (62 pt), à `space-6` du bas, marges `space-4`. Rayon `radius-full`.
- Onglet actif : fond `fill-3`, icône et libellé `tint`. Libellés 10–11 pt, 600.
- L'onglet Prominent porte l'action la plus fréquente : Coach (Natif), Lancer la prochaine vidéo (Nuit calme), Rechercher (Carnet de saison).
- Le contenu défile dessous : prévoir un dégradé de fond de 120 pt sous la barre.
- Le consommateur fournit : les 3 onglets (icône SF Symbol + libellé), l'onglet actif, l'action Prominent.
